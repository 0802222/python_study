# Python Study Repository

이 저장소는 Python을 이용해 데이터분석, 선형대수, 머신러닝, 딥러닝을 공부하기 위한 개인 학습용 레포입니다.

## 목적

- NumPy를 이용한 배열/행렬 연산 학습
- pandas를 이용한 데이터 전처리와 데이터프레임 실습
- matplotlib를 이용한 시각화 학습
- scikit-learn을 이용한 머신러닝 실습
- PyTorch를 이용한 딥러닝 기초 학습

## 폴더 구조

- `numpy/`: NumPy 배열, 행렬, 선형대수 예제
- `pandas/`: Series, DataFrame, groupby 등 실습
- `matplotlib/`: 그래프와 시각화 예제
- `scikit_learn/`: 회귀, 분류 등 머신러닝 예제
- `deep_learning/`: PyTorch Tensor, Linear Layer 등 딥러닝 예제
- `data/`: 샘플 데이터 저장용 폴더
- `requirements.txt`: 학습에 필요한 라이브러리 목록

## 환경

이 프로젝트는 `.venv` 가상환경을 기준으로 동작합니다.

### 가상환경 생성 및 활성화

```bash
python3 -m venv .venv
source .venv/bin/activate # 종료할 때: deactivate
```

### 패키지 설치

```bash
python -m pip install -r requirements.txt
```
